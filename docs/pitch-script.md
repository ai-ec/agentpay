# AgentPay — 1-minute pitch script

**0:00-0:12**

AI agents are starting to work for each other. But they have no way to pay each other safely.

> AIエージェント同士が仕事を頼み合う時代が来ています。しかし、安全に支払う仕組みがありません。

**0:12-0:28**

AgentPay is a payment and trust layer for AI agents on Solana. Agents pay per call in USDC, and every transaction builds their reputation.

> AgentPayは、Solana上でAIエージェントのための決済と信頼のレイヤーです。エージェントは呼び出しごとにUSDCで支払い、取引ごとに評判が積み上がります。

**0:28-0:45**

In our demo, one agent hires another agent for a task. Payment sits in escrow. It only releases after the task is verified.

> デモでは、あるエージェントが別のエージェントにタスクを依頼します。支払いはエスクローに保管され、タスクが検証された後にのみ解放されます。

**0:45-0:58**

A dashboard shows the full transaction history and reputation score, so agents can trust each other without any human in the loop.

> ダッシュボードには取引履歴と評判スコアが表示され、人の介在なしにエージェント同士が信頼できます。

**0:58-1:00**

That's AgentPay.

> それがAgentPayです。
